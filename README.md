# Sid Meier Perspective · 席德·梅尔游戏设计顾问

当你在设计游戏时遇到瓶颈，不妨把这个 Skill 加入你的 AI 助手。它借鉴席德·梅尔公开分享的游戏设计方法，帮你从玩家的视角审视选择、反馈和整体体验，把模糊的想法变成可以测试的设计问题。

**适合用来：**
- 评审玩法、系统与游戏策划方案，找出缺少取舍或反馈的环节。
- 分析核心循环和副玩法如何共同影响玩家体验。
- 为不确定的想法设计小规模可玩原型与验证方式。
- 练习游戏设计思考，或围绕真实经历准备游戏策划面试。

## 安装与使用

将仓库下载后，把包含 `SKILL.md` 的文件夹复制到支持 Agent Skills 的工具的技能目录中。例如，在 Codex 中可将其放在 `~/.codex/skills/sid-meier-perspective/`。重新加载工具后，可以尝试：

> 用席德·梅尔的视角，帮我评审这个战斗系统：玩家有哪些真正有意义的选择？

也可以请求它帮助设计原型、分析一个玩法的取舍，或一步步练习游戏设计。

## 说明

本 Skill 是对公开资料的分析性整理，并非席德·梅尔本人创作或认可。对新方案的评价是基于框架的推断，不代表其真实立场。原文中的公开来源链接可供核查；目前仓库不包含正文提到的 `references/` 研究记录。

## English

When you need a fresh perspective on a game design challenge, add this skill to your AI assistant. Drawing on Sid Meier’s publicly shared design principles, it helps you examine choices, feedback, and the overall player experience—and turn vague ideas into questions you can test.

**Use it to:**
- Review mechanics and design proposals for meaningful choices and clear feedback.
- Explore how core loops and side activities shape the whole experience.
- Turn uncertain ideas into small playable prototypes and practical tests.
- Practice game design thinking or prepare for interviews using your own experience.

## Install and use

Download this repository and copy the folder containing `SKILL.md` into your Agent Skills-compatible tool’s skills directory. For Codex, for example, use `~/.codex/skills/sid-meier-perspective/`. Reload the tool, then try:

> Using Sid Meier’s perspective, review this combat system. What meaningful choices does the player have?

You can also ask for help designing a prototype, examining trade-offs, or practicing game design step by step.

## Note

This skill is an analytical interpretation of public material. It was not created or endorsed by Sid Meier. Judgments about new designs are inferences from the framework, not statements of his actual views. The skill includes links to public sources; the `references/` research notes mentioned in the text are not currently included.
